# Saudi ZATCA Phase 2 POS v4.0 (Final Production Ready)

## Key Features
- **Instant B2C Billing + Daily Z-Close Batch Sync:** B2C invoices print in 0.2s and queue for batch reporting to ZATCA within 24 hours (manual Z-Close button + automatic hourly scheduler). B2B invoices clear in real time.
- **4-Digit Auto-Login:** Unlocks automatically on typing the 4th PIN digit.
- **80mm & 58mm Thermal Printer Support + Auto-Print:** Switch thermal paper size in settings; supports Windows `--kiosk-printing` silent print and mobile RawBT.
- **Simplified Shop Settings + Full Bank Details:** Shop Name (EN/AR), WhatsApp No, Single Arabic Address box, plus Bank Name, Account Number, and IBAN printed on receipts & A4 PDFs.
- **Full Backup, Restore & Post-Testing Reset:** Download full JSON backup, restore anytime, and wipe test transactions back to zero before live launch.
