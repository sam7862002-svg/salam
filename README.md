# Saudi ZATCA Phase 2 POS v3.0 (Enterprise Edition)

## Complete Feature List
1. **Database Auto-Heal (`last_icv` Fix):** Automatically initializes `company_settings`, default `Walk-in Cash Customer`, and `staff_users` on server start.
2. **Unified Barcode & Live Search Dropdown:** Scan a barcode OR type any part of an English/Arabic product name for instant dropdown selection.
3. **Auto-ALL CAPS & Auto-Arabic:** Product & Party English names automatically format in ALL CAPS (`UPPERCASE`) and auto-translate to Arabic.
4. **Bulk Excel Import & Sample Templates:** Download ready-to-use Excel templates and bulk-upload Products and Customers/Vendors.
5. **Edit & Delete Management:** Edit or safely delete Products, Customers, Vendors, and Staff PINs.
6. **Customer/Vendor Live Balance & Bill Balance:** Displays live credit balance upon selection and prints Previous Balance & Net Closing Balance on 80mm thermal receipts and A4 PDFs.
7. **Multi-Staff PIN Users:** Create individual PINs for Admin and Cashiers; tracks which staff issued each invoice.
8. **15% VAT Inclusive Pricing, Single-Shot Red-Line Camera Scanner, Smart Cart Grouping, Instant Quick-Add, Discreet Cost Ref, A4 PDF Print & WhatsApp PDF Share, 4 Separate VAT Excel Exports.**
